# Healthy Recipes Finder

A modern, fast, and responsive React web application designed to help users discover nutritious, whole-food recipes in seconds. Filter through curated dishes, check prep times, and view complete step-by-step cooking instructions with zero fuss.

**Live Demo:** [ourrecipefinder.netlify.app](https://ourrecipefinder.netlify.app/)

---

## Features

* **Quick Search & Filtering:** Dynamically filter recipes by name or ingredient in real-time.
* **Detailed Recipe Insights:** View complete ingredient lists, step-by-step instructions, total cook times, and serving sizes.
* **Responsive UI:** Fully optimized layout for mobile, tablet, and desktop viewports.
* **Single Page Navigation:** Powered by React Router with fallbacks for seamless page reloads.

---

## Tech Stack

* **Frontend:** React, HTML5, CSS Modules
* **Build Tool:** Vite
* **Routing:** React Router (`react-router-dom`)
* **Deployment:** Netlify
